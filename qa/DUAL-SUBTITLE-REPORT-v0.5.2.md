# v0.5.2 작업 시간 정지·한국어/일본어 동시 자막

검증일: 2026-10-15~16 (KST). 사용자 Chrome은 조작하지 않았으며 직접 설치할 수 있는 개인용/공개용 ZIP을 제공합니다.

## 작업 경과 시간이 계속 늘어난 원인과 수정

기존 팝업은 완료 여부와 관계없이 `현재 시각 - startedAt`을 매번 표시했습니다. 번역 작업의 재생 상태 보고도 `updatedAt`을 갱신하므로 마지막 상태 갱신 시각을 완료 시각으로 사용하는 방식으로는 해결되지 않습니다.

`jobClock.ts`에서 실제 진행 중인 작업과 종료 상태를 구분합니다. `workElapsedMs`에 종료한 작업 시간을 누적하고 `workActiveSince`에 현재 진행 구간의 시작을 기록합니다. 완료/오류/수동 대기/선택/중단 상태에서 더 진행하는 작업이 없으면 `finishedAt`을 기록하고 시계를 멈춥니다. 재생 이동·팝업 재열기·싱크 변경 등으로 상태가 갱신되어도 종료 시간은 늘어나지 않습니다.

한국어가 적용되어도 일본어 추가 검색이 진행 중이면 계속 계산합니다. 번역, 플레이어 준비 대기와 예약된 AUTO 재시도도 진행 상태입니다. 완료 뒤 새 일본어 검색을 시작하면 기존 누적 시간에 새 작업 구간만 더하며 중간 유휴 시간은 제외합니다. 캐시된 일본어 원문을 켜고 끄는 경우에는 기존 완료 시간을 유지합니다. 일본어/영어 번역 화면에도 경과 시간과 종료 표시를 추가했습니다. 구버전 저장 상태는 마지막 저장 시각을 사용해 증가를 멈추며 새 작업부터 정확한 종료 시각을 기록합니다.

## 일본어 추가 자막 사용

팝업 또는 설정의 **일본어 원문 함께 보기**를 켭니다. 기존 한국어를 위에 유지하고 일본어를 아래에 표시합니다. 기본값은 꺼짐이며 기존 번역 서버·AUTO/수동 설정을 보존합니다.

설정의 **추가 자막**에서 일본어 크기(기본 22px, 12~72px)와 추가 싱크(-10~10초)를 조절합니다. 공통 싱크에 일본어 싱크를 더하며 양수는 일본어를 먼저, 음수는 늦게 표시합니다. 저장 또는 팝업 스위치는 현재 영상에 반영되고 한국어 검색/번역을 재실행하지 않습니다. 스위치는 즉시 반응하고 비동기 저장 실패 시 이전 상태로 돌아가며, 겹친 상태 조회가 최신 스위치 선택을 덮어쓰지 않도록 했습니다.

| 한국어 자막 경로                       | 일본어 원문 확보                                                      |
| -------------------------------------- | --------------------------------------------------------------------- |
| Jimaku/Kitsunekko 일본어 → 한국어 번역 | 이미 받은 원문을 재사용. 추가 검색·다운로드·번역 없음.                |
| Anissia 한국어                         | 한국어를 먼저 적용하고 Jimaku → Kitsunekko → 내장 일본어를 별도 확인. |
| AUTO 일본어 검색 실패 후 영어 번역     | 외부 일본어 검색을 반복하지 않고 내장 일본어만 확인.                  |
| 수동 영어 번역                         | 추가 옵션을 켜면 외부/내장 일본어를 별도로 확인.                      |

일본어가 없거나 실패해도 한국어는 유지하고 상태창에 원인을 표시한 뒤 경과 시간을 멈춥니다. 영어를 일본어로 바꾸거나 일본어를 생성하지 않습니다. 내장 자막은 일본어 언어 태그만 선택하며 파일 인코딩에 Shift-JIS를 포함합니다.

## 렌더링·캐시·취소

- 한국어/일본어 Cue를 별도로 유지하고 각 파일의 실제 시간으로 표시합니다. ID/줄 나눔이 달라도 충돌하지 않습니다. 각 언어의 크기·싱크를 독립 적용합니다.
- 점진 번역의 첫 한국어 Chunk와 전체 일본어 원문을 동시에 표시하며 나머지 한국어 번역은 계속됩니다. 원문을 중복 다운로드하거나 번역하지 않습니다.
- 일본어 Cue와 출처를 회차 캐시에 함께 저장합니다. 기존 일본어 번역 캐시의 `originalCues`도 재사용합니다. 완료된 회차의 일본어 원문 재방문은 추가 파일 다운로드가 없습니다.
- 추가 검색은 별도 AbortController로 관리하고 부모 회차 취소 신호를 연결합니다. 옵션 끄기·회차 변경 시 취소하며 늦은 결과를 거부합니다. Content Script도 오래된 epoch의 일본어 메시지를 거부하고 새 회차에서 두 언어를 모두 초기화합니다.
- 플레이어/iframe 교체 시 두 언어를 복원합니다. MV3 worker가 종료되어도 session에 남긴 완료 자막으로 표시 옵션을 복원하며 한국어 작업을 다시 시작하지 않습니다. 복원 시 현재 epoch를 다시 확인해 새 job을 덮어쓰지 않습니다.
- 컨테이너 전체화면은 두 줄 오버레이를 유지합니다. video 자체 전체화면은 한국어+일본어를 하나의 native Cue로 합쳐 표시합니다. 원래 사이트 자막은 중복 표시를 막기 위해 숨기고, 직접 바꾼 선택은 보존하며 필요한 시점에 복원합니다.
- 개인용 `<all_urls>`, 공개용 known host, 초기 권한 가이드와 업데이트 확인 구조를 유지합니다. 새 runtime 권한 요청은 없습니다. API Key는 프레임에 전달하지 않으며 복원용 원본/캐시 내부 정보도 렌더러 메시지에서 제외합니다.

## 검증 범위와 제한

브라우저 검사는 새 격리 Chromium의 실제 MV3 worker, Content Script, IndexedDB/session cache, renderer와 모의 사이트/자막/모델/GitHub 응답을 사용했습니다. 닫힌 Shadow DOM 안의 두 언어도 CDP로 확인했습니다. 컨테이너 전체화면은 실제 실행했고 video 자체 fullscreen은 renderer 분기를 모의 실행했습니다. worker 재시작 후 옵션 복원은 unit test로 검증했습니다. 실제 사용자 Chrome 설치, 최신 원격 사이트/스트림 재생, 외부 자막 존재 여부와 번역 모델 품질은 이번 검사로 보장하지 않습니다.

일본어 파일이 실제로 없으면 동시 표시할 수 없습니다. 별도 배포 파일은 영상 릴리스에 따라 싱크 차이가 있을 수 있어 일본어 전용 조절을 제공합니다. Chrome native 자막은 일본어 개별 크기/색을 그대로 지원하지 않을 수 있습니다. 공개용의 새 배포 host는 기존 초기 접근 등록 또는 manifest 업데이트가 필요합니다.

기본 개인용 ZIP의 `extension` 내용으로 기존 설치 폴더를 교체한 뒤 Chrome 확장 새로고침(↻)과 영상 새로고침을 진행하세요. 이후 팝업의 **일본어 원문 함께 보기**를 켜면 됩니다. 저장소 접근이 있는 GitHub 계정으로 다른 컴퓨터에서도 Release를 받을 수 있습니다.
